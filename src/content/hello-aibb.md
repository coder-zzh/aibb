## 为什么需要自己的博客

在信息爆炸的时代，拥有一个属于自己的博客，不仅是技术的体现，更是思想的沉淀。

### 技术选型

这次选择了 **Vite + React** 的组合，理由很简单：

- Vite 开发体验极佳，热更新秒级响应
- React 生态成熟，组件化开发清晰
- Markdown 写文章，专注内容本身

### 部署流程

```bash
npm run build
# dist/ 目录就是最终的静态文件
```

> 写得好的代码，本身就是最好的文档。
